# AgroTech Comunitária

Projeto desenvolvido para a Atividade A3 da disciplina de Programação Orientada a Objetos e Algoritmos.

##  Objetivo
Desenvolver um sistema em Java para auxiliar na organização e gestão de hortas comunitárias, promovendo sustentabilidade, organização social e uso consciente de áreas verdes.

## Problema Abordado
Muitas hortas comunitárias enfrentam dificuldades por falta de organização, controle de participantes, planejamento de cultivo e acompanhamento de colheitas, o que pode levar ao abandono do espaço.

## Solução Proposta
O sistema AgroTech Comunitária oferece uma solução computacional orientada a objetos para organizar:
- Voluntários
- Plantas
- Registros climáticos
- Colheitas

##  Estrutura do Projeto
O projeto está organizado em pacotes, seguindo uma arquitetura inspirada no padrão MVC:
- **model:** classes de domínio do sistema
- **controller:** controle e lógica de funcionamento
- **view:** interação com o usuário via console

## Tecnologias Utilizadas
- Java
- Programação Orientada a Objetos
- GitHub
